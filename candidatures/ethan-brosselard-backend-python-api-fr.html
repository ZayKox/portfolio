Exemples de réalisations

Primotheus : estimer un bien à partir de transactions comparables

J’ai contribué avec le CTO au backend FastAPI d’une plateforme immobilière. Les données de transactions DVF sont nettoyées puis stockées dans PostgreSQL. L’estimation recherche des ventes comparables selon la localisation, le type de bien et la surface, filtre les valeurs atypiques et calcule une valeur estimée. Le backend permet aussi de recalculer les estimations après une modification du bien ou par traitement groupé.

Thésorimed : automatiser la préparation des données médicament

J’ai réalisé la majeure partie du backend Flask de la plateforme interne Thésorimed. Les traitements récupèrent et mettent à jour les notices et les résumés des caractéristiques du produit (RCP), extraient leurs sections et préparent les données pour les bases SQL. Des pipelines avec Pandas traitent aussi les prix et remboursements des médicaments ; les documents et résultats d’extraction sont stockés sur AWS S3.

RAG : interroger les documents utiles dans leur contexte

En santé, j’ai contribué à un RAG pour poser des questions sur les notices et RCP des médicaments. Pour Primotheus, le RAG sert à interroger les informations immobilières fournies par l’utilisateur : ses biens et ses documents, dont le contenu est extrait par OCR. Ces contributions associent recherche vectorielle et services OpenAI ; l’objectif immobilier est de travailler sur les données apportées par chaque utilisateur.

Primotheus : relier le backend aux workflows n8n

Le backend Primotheus s’intègre à des workflows n8n pour traiter des événements et synchroniser des informations avec des outils métier. Ce contexte complète ma pratique de Python, FastAPI, des API REST et des traitements de données, avec des tests pytest et une livraison par Docker et CI/CD.
